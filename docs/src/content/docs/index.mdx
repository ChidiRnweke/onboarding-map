import { CardGrid, LinkCard } from '@astrojs/starlight/components';

export const base = import.meta.env.BASE_URL.replace(/\/?$/, '/');

Anything someone has to learn — a codebase, a cloud platform, a physics course — arrives as a pile
of documents written for people who already know it. onboarding-map turns that pile into one
picture: everything they will meet, and a single path through it. You bring the content; the package
draws the map.
