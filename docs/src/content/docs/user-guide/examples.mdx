The package ships two templates: a small starter and a complete Physics map. This documentation also
uses a map of the onboarding-map project. Each example is live beside the file that produces it. Open
the map full screen to explore it; the download link gives you its TypeScript source.

## Starter

The smallest useful starting point: two regions, a few items and two stages. This is what `init`
copies into a new project. Replace it with your subject, or ask your agent to expand it.
