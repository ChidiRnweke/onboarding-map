export const base = import.meta.env.BASE_URL.replace(/\/?$/, '/');

A codebase, a cloud platform or a course can take weeks to learn. The map puts the important parts
in one picture, then gives the newcomer one route through them. Its data lives in one file. A coding
agent can draft and maintain that file from your notes, docs or codebase; onboarding-map renders it
as a static site.
